# Minecraft FPS Booster

**Performance Optimization Mod for Minecraft 1.20 – 1.21**

High-performance FPS booster designed to significantly increase frame rate, reduce lag spikes and optimize rendering.  
Clean modular architecture with full configuration support for both Forge and Fabric.

---

### What this is

A complete performance optimization mod that provides:
- Aggressive FPS boosting  
- Smart entity & chunk culling  
- Memory and garbage collection optimization  
- Render pipeline improvements  
- Fully configurable settings  
- Low overhead design  

---

### Features

- Advanced render optimizer  
- Entity culling system  
- Chunk loading optimization  
- Memory management  
- Dynamic performance profiles  
- Compatible with most other mods  
- Forge & Fabric support

### Configuration

All settings are stored in `config/default.json`:

- Render distance optimization  
- Entity culling strength  
- Chunk loading priority  
- Memory cleanup interval  
- Performance profile (Balanced / Aggressive / Ultra)
